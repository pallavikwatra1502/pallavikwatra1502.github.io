# Pallavi Kwatra Portfolio Website

A premium static portfolio for a UK Senior Data Engineer / GCP Cloud Data Engineer, designed for GitHub Pages.

## Files
- `index.html` — portfolio website
- `styles.css` — responsive visual design
- `script.js` — animations, mobile nav and portfolio chatbot
- `assets/Pallavi_Kwatra_Resume.pdf` — downloadable CV

## Publish on GitHub Pages
1. Create a new GitHub repository named `PALLAVIKWATRA1502.github.io`.
2. Upload all files from this folder into the repository root.
3. Commit the files to the `main` branch.
4. Go to **Settings > Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select `main` and `/root`, then save.
7. Your live site will be available at `https://PALLAVIKWATRA1502.github.io/` after GitHub finishes deployment.

## Chatbot note
The included chatbot is a fast static portfolio assistant that answers from pre-written knowledge in `script.js`. It works on GitHub Pages without API keys or backend hosting. To make it a real AI chatbot like a GPT/RAG assistant, deploy a backend on Vercel/Render/Cloud Run and connect it to OpenAI/Gemini with your resume and project data.
